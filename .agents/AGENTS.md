# Strict Branding Rule: Fonts
You MUST strictly use only the brand fonts for this website anywhere text is rendered or styled:
1. `Clash Display`
2. `Panchang`

Do not use `monospace`, `sans-serif` (unless as a fallback for the brand fonts like `'Clash Display', sans-serif`), system fonts (like Arial, Inter, Roboto), or any other fonts. This rule applies to all current code, future changes, and any refactoring of previously done things.
